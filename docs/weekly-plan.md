# 五周排期与计划配置修订

用户明确授权扩展排期，并保留原计划与学习记录。

新增可选 PlanConfig.name / strategy 和 RescheduleRequest.config，旧客户端省略字段仍使用原连续排期。完整配置编辑沿用预览与确认接口，确认产生新修订。历史修订固定任务范围，新范围复用对应任务ID与真实目录完成状态，不删除旧计划任务或用户进度。

WEEKLY_35 要求35个连续日期、4门理论课、逐日完整容量；第1–4周各一科，第5周为真实模板真题/复习任务。无模板科目补独立REVIEW计划任务，明确估时60分钟，跳转已有练习。考试截止与未知日期规则继续有效；不足不跨周占用其他科目的窗口。

V7仅允许独立REVIEW无模板，不变更已发布课程模板、不删除旧数据。所有旧行仍符合约束。代码回退后V7可保留；不要删除迁移或使用Flyway clean。

验证：28项单元测试、13项临时MySQL接口测试通过，包括配置预览、容量0、换科目、保留历史范围和进度、实际状态冲突、完整五周和无模板复习任务。临时数据库与现有用户数据库隔离。

共享根目录不属于Git仓库，附weekly-plan-contract.patch保存OpenAPI增量，生成的业务校验快照与前端模型同步。
