# 答题图片自动批改的后续边界

本次成绩图片仍是私人存档，上传不会创建批改任务、改变成绩或返回自动评分。旧 grading 归档只读。以下是可在现有模块上实施的后续协议，尚无生产接口或工作程序。

## 拥有的数据与状态

assessment拥有答卷、题目版本、评分标准版本、评分结果与人工核对；files拥有私有字节和访问授权；exams拥有真题练习成绩及修订快照；operations拥有任务领取和恢复基础设施。工作程序不直接写业务表，不取得用户JWT，不使用用户网页存储地址。

新增答卷时固定 owner_id、course/cycle、paper版本、每张文件id/sha256、每题评分标准版本和总分规则。题目、评分标准与提交图片在任务期间不可原地替换；替换需要新版本/新任务。成绩关联 submission_id 与 grading_result_id，不覆盖原手工成绩来源。

状态：QUEUED → LEASED → RESULT_RECEIVED → VALIDATING → REVIEW_REQUIRED/APPROVED；可恢复失败进入 RETRY_WAIT，超过策略次数进入 FAILED。取消进入 CANCELLED，过期租约回队。FAILED/REVIEW_REQUIRED不会授予通过或预测资格。

## 领取、续租与回传

网页申请须验证本人答卷归属、完整文件集、有效评分标准和幂等键；事务提交后任务才可领取。工作程序通过独立最小权限worker凭据申请任务。MySQL原子领取生成随机 lease_token、attempt、lease_until；续租必须匹配工作程序身份、task_id、当前token且未取消。工作程序只获得短期授权的图片读取能力和固定评分标准，不获取其他用户附件。

常开服务器的Codex工作程序领取 → 获取真实图片和固定评分标准 → 批改 → 带 task_id、lease_token、attempt、result_id、标准版本/图片摘要回传。回传先持久化原始结果，不立即授予通过；重复result_id+摘要返回原确认，冲突内容拒绝，旧租约回传不修改活动任务。工作程序崩溃后租约回收，新领取者不得覆盖已经接受的结果。

服务器验证每题ID、标准版本、图片摘要、分值上限、扣分证据、总分算术和结果完整性；非法结果进入失败/人工核对，不自动截断成“有效成绩”。人工核对修改形成新结果版本、核对人/理由/时间与审计；通过验证并获批准后，在同一事务更新任务、答卷状态、成绩修订和审计。自动图片评分是否可以授予检测通过/计入预测仍需单独确认，默认不授予。

## 必要的后续交付

真实评分标准数据、worker部署与凭据轮换、领取/续租/回传接口、恶意回传校验、图片授权、租约竞争与超时恢复测试、人工核对页面和实际服务器演练。当前保留的持久任务与私有文件基础可复用，不能把本设计当成已上线能力。范围不包含自动出题、支付或社交。
